# Food Rescue & Donation Management System

## Project Overview
The Food Rescue & Donation Management System is a MySQL database project.
It helps manage surplus food donations from donors to organizations.
The system stores donor, food, organization, donation, and feedback details.

## Objectives
- Manage donor information
- Track available food items
- Manage food donations
- Track organizations receiving food
- Store feedback and ratings
- Generate useful reports using SQL

## Technologies Used
- MySQL
- MySQL Workbench
- GitHub

## Database Tables
1. Donors
2. Food Items
3. Organizations
4. Donations
5. Feedback

## SQL Concepts Used
- SELECT and filtering
- Aggregate functions
- Joins
- Subqueries
- Views
- Stored Procedures
- Stored Functions
- Triggers
- Transactions
- Indexes

## Project Structure
- `sql` – SQL project file
- `screenshots` – MySQL Workbench output screenshots
- `docs` – Project presentation

## Conclusion
This project demonstrates how SQL can be used to manage food donation
activities and generate meaningful information from a relational database.
